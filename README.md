
# C Programming and Data Structures

## About This Repository
This repository contains C programming examples and Data Structures implementations developed for learning and practicing fundamental programming concepts.

It includes programs covering pointers, memory management, arrays, linked lists, stacks, queues, hashing, tree traversals, and time complexity analysis.

## Topics Covered

### 1. Pointers
- Pointer basics
- Reading values using pointers
- Pass by reference
- Swapping values using pointers

### 2. Dynamic Memory Allocation (DMA)
- malloc()
- calloc()
- realloc()
- strdup()

### 3. Arrays
- Array traversal
- Insertion at beginning
- Deletion at beginning
- Deletion at a specific position
- Deletion at the end
- Matrix transpose using pointers and DMA

### 4. Linked Lists
- Creating nodes using structures
- Insertion at beginning
- Insertion at end
- Insertion at a specific position
- Deletion at beginning
- Deletion at end
- Deletion at a specific position

### 5. Stack
- Push operation
- Pop operation

### 6. Queue
- Enqueue operation
- Dequeue operation
- Peek operation
- Fixed capacity implementation using CAP

### 7. Hashing
- Hash operations

### 8. Trees
- Tree traversals

### 9. Time Complexity
- O(n) – Linear Time Complexity
- O(n²) – Quadratic Time Complexity

### 10. Other C Programs
- Finding maximum and sum
- String write and update operations

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Editor: VS Code

## How to Run the Programs

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to the Folder

```bash

```

```bash

```

### Step 4: Execute the Program

```bash
./output
```
